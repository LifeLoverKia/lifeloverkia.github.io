# Reading links

Publication access metadata was reviewed on 31 October 2026 using OpenAlex work records keyed by DOI, the publisher pages for the recent subscription reviews, and Chiara Saracini’s public ResearchGate publication pages. A ResearchGate URL is stored only after matching an actual individual publication page; no search links or guessed publication identifiers are used. Publisher open access and repository availability are distinguished. No new access-status badges are shown to visitors.

All eleven DOI records reported as closed at this review have a verified individual ResearchGate page. Green-access works can also link to ResearchGate when the publisher version is not open. Direct full-text URLs are included when identified in the metadata; access policies may subsequently change.

The preprint connected to the developmental cognitive neuroscience article is on bioRxiv, DOI 10.64898/2025.11.29.691280. It is labelled simply “Preprint”. Links to ORCID work records and “Related version” links are no longer rendered. The ORCID profile remains available in the introductory profile links.
